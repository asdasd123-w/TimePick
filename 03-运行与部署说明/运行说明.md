# 拾光 TimePick · 运行说明

> 从零把网站跑起来大约需要 5 分钟（不含 `npm install` 的下载时间）。
> 前提：机器上已经装好 Node.js，**不需要**装 MySQL / Redis，也不需要安装 Cocos Creator。

---

## 一、这个项目是什么结构

```
源码/     ← 一个完整的 Node 工程（前端 + 后端在同一个目录）
├─ src/                    前端源码：Vue 3 单文件组件、路由、状态
├─ public/                 静态资源（含 public/room3d：3D 房间的构建产物，已内置）
├─ server/                 Express 后端：接口、SQLite、3D 房间数据
│  ├─ index.js             所有 HTTP 接口（单入口，按 action 分发）
│  ├─ room.js              3D 房间的家具/布局/访客数据
│  ├─ schema.sql           建表语句（首次启动自动执行）
│  └─ db-driver.js         SQLite 驱动自适应（原生 → Node 内置 → WASM）
├─ scripts/                构建与运维脚本
├─ index.html              Vite 入口
├─ vite.config.js          构建配置
└─ package.json            依赖与命令

02-3D房间工程/              ← Cocos Creator 3.8.8 工程源码（看代码用，跑网站不必打开）
├─ assets/                 场景、脚本（TypeScript）、模型（.glb）
├─ settings/ profiles/     工程配置
└─ package.json            creator.version = 3.8.8
```

**前端和后端为什么放在同一个目录**：它们共用一份 `package.json`（前端依赖 vue/vite，后端依赖
express，装在同一次 `npm install` 里），后端还负责托管前端构建产物。拆成两个目录就装不起来、
也跑不起来，所以保持一个工程。

---

## 二、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node.js | **≥ 20.11**（实测 22.22 可用） | `node -v` 检查 |
| 操作系统 | Windows / macOS / Linux | 路径处理已做跨平台兼容 |
| 数据库 | **不需要单独安装** | SQLite 单文件，首次启动自动建库建表 |
| 浏览器 | Chrome / Edge 最新版 | 3D 房间需要 WebGL 2.0 |

## 三、四步启动

### 第 1 步：安装依赖

```bash
cd 源码
npm install
```

> 如果机器上编译不了原生模块（报 node-gyp / python 相关错误），改用：
> `npm install --omit=optional --no-audit --no-fund`
> 这样会跳过 `better-sqlite3` 和 `sharp`，运行时自动回落到 WASM 版 SQLite，功能完全一致，只是稍慢。

### 第 2 步：配置环境变量

把 `03-运行与部署说明/环境变量示例.env` 复制到**源码根目录**，重命名为 `.env.local`：

```bash
cp ../03-运行与部署说明/环境变量示例.env .env.local
```

最少只需要改一项 `JWT_SECRET`（随便一串长随机字符即可）。三个 AI 密钥可以留空——
留空时「AI 取标题 / AI 封面 / 图生视频」这些功能会返回"未配置密钥"的提示，
**其余功能（记忆库、广场、3D 房间、关注、私信）都不受影响**。

### 第 3 步：构建前端

```bash
npm run build
```

这一步做三件事：Vite 打包到 `dist/` → 把 `public/` 里的资源补进去 → 再复制一份到 `webroot/` 作为备份。
产物约 240 MB，主要是 3D 房间的资源，耗时通常 30–60 秒。

> 交付包里**没有带 `dist/`**（打包上传会超限），所以这一步不能跳过。
> 不构建直接启动，浏览器打开会是 404。

### 第 4 步：启动

```bash
node server/index.js
```

看到监听 8787 的日志后，浏览器打开：

**http://localhost:8787**

前端页面、`/api` 接口、上传文件，全部由这一个进程、这一个端口提供。

## 四、注册账号与创建管理员

### 4.1 注册

页面上点注册，需要填：

| 字段 | 规则 |
|---|---|
| 手机号 | 11 位，1 开头、第二位 3–9 |
| 密码 | 至少 6 位 |
| 昵称 | 不能与已有用户重复 |
| 注册口令 | 默认 **优乐美**（服务端 `REGISTER_PASSPHRASE` 可改） |

### 4.2 创建第一个管理员

注册接口不会自动给管理员权限，新库里所有账号都是普通用户。**先把管理员建出来**：

```bash
npm run admin:grant -- 13800138000     # 换成你刚注册的手机号
```

然后退出重新登录，左侧就会出现「管理中心」。

之后在「管理中心 → 用户管理」里，用 `设为管理员` 给其他人授权，不用再跑脚本。

> 超级管理员（不可删除、不可禁用、不可取消、密码不可重置）由环境变量
> `SUPER_ADMIN_USERNAME` 决定；示例文件里填的是 `13800138000`，**改成你自己注册用的手机号**。
> 如果你想让自己注册的账号成为超级管理员，把 `.env.local` 里的
> `SUPER_ADMIN_USERNAME` 改成你的手机号，再 `npm run admin:grant -- 你的手机号`。

### 4.3 想快速看到"有内容"的样子

```bash
npm run seed:demo
```

写入 8 个演示用户、5 条广场动态和评论（幂等，重复执行不会重复插入）。演示账号密码统一
`demo123456`，其中 `优乐美 / 002529` 是管理员。

> 这个脚本直接用 `better-sqlite3`。如果你是用 `--omit=optional` 安装的，它会报
> "Cannot find module 'better-sqlite3'"，此时跳过即可——自己注册几个账号手动发内容效果一样。

## 五、开发模式（改代码时用）

```bash
npm run dev      # 前端热更新，http://localhost:5173
npm run server   # 后端，http://localhost:8787
```

两个都开着，前端通过 `VITE_CLOUD_API_BASE` 指向后端（`.env.local` 里配 `http://localhost:8787/api`）。

改完前端建议跑一次静态检查，能抓出"构建通过但运行时报错"的问题：

```bash
npm run check:undef
```

## 六、在手机上访问（局域网自测）

网站是按「响应式 / 移动优先」做的，手机浏览器可直接打开完整功能，不需要装 App。
后端 `server/index.js` 里是 `app.listen(PORT, '0.0.0.0')`，默认已经监听所有网卡，**不用改代码**。

### 6.1 三步打开

1. **查本机在局域网里的 IP**

   ```bash
   # Windows
   ipconfig
   #   找「无线局域网适配器 WLAN」下的 IPv4 地址，例如 192.168.1.23
   # macOS / Linux
   ifconfig | grep "inet "
   #   找 en0 / wlan0 的 192.168.x.x 或 10.x.x.x
   ```

2. **手机连到同一个 Wi-Fi**（和电脑同一个路由器 / 同一个手机热点）

3. **手机浏览器输入** `http://<上面那个 IP>:8787`

   > 一定要带 `http://`。只输 `192.168.1.23:8787`，部分浏览器会把它当成搜索词。

首次在 Windows 上启动时系统会弹防火墙提示，要勾选**「专用网络」并允许**，否则手机能连上 Wi-Fi 但打不开页面。

### 6.2 打不开怎么排查

| 现象 | 原因 / 解决 |
|---|---|
| 一直转圈、超时 | IP 变了。DHCP 每次重连都可能换地址，重新查一次 IP |
| 电脑自己能开、手机不行，且换了 IP 也不行 | 这个 Wi-Fi 开了**客户端隔离（AP isolation）**。校园网、酒店网、公司网、部分光猫默认会开，设备之间互相看不见。用手机开热点、电脑连热点，再查一次 IP 即可 |
| 提示拒绝连接 | 服务没启动，或启动时端口不是 8787 |
| 页面能开但 3D 房间空白 | 手机浏览器没开硬件加速，或 WebGL 2.0 不可用（老机型/iOS 低版本） |

### 6.3 手机上哪些交互能用

| 功能 | 手机上怎么操作 |
|---|---|
| 主导航 | 左侧保留图标栏，按钮 44×44 |
| 2D 小猫 | 全站显示，按屏宽自动缩到 88–132px |
| 3D 房间转视角 | **单指拖动** |
| 3D 房间换机位 | 顶部「小屋 / 室内 / 花园 / 书桌 / 岛体」五个按钮（手机上无滚轮，所以不依赖缩放） |
| 让小猫走过去 | **双击地板**；点小猫打开互动菜单 |
| 海报类页面 | 竖屏时海报退成顶部 124–148px 装饰条，内容改单列整宽 |

> 布局断点是 `(max-width: 767.98px)` 加上 `(max-width: 1024px) and (orientation: portrait)`，
> 后者是给平板竖屏的——768 宽的 iPad 竖屏如果按桌面海报版式缩放，控件会小到只剩 18px。

## 七、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 打开首页是 404 或空白 | 忘了 `npm run build`，`dist/` 不存在 |
| 页面能开但没有数据、接口 500 | 看启动终端里的报错；多半是 `.env.local` 里的 `JWT_SECRET` 没配 |
| 3D 房间转圈很久 | 首次加载要下 ~130 MB 资源（沙箱环境冷启动约 20–25 秒），之后走缓存会快很多 |
| 3D 房间一片空白 | 浏览器没开硬件加速，或 WebGL 2.0 不可用 |
| `npm install` 报 node-gyp 错误 | 用 `npm install --omit=optional` |
| 管理中心进不去 | 该账号 `role` 不是 1，跑 `npm run admin:grant -- 手机号` |
| 注册提示"口令不正确" | 注册口令默认是「优乐美」，可在 `.env.local` 改 `REGISTER_PASSPHRASE` |
| 端口被占用 | `PORT=9000 node server/index.js` 换端口 |
