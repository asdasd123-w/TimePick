# 数据库说明

## 一、是什么

| 项 | 值 |
|---|---|
| 类型 | **SQLite**（单文件，无需安装任何数据库服务） |
| 文件位置 | `01-网站源码-前端与后端/server/data/timepick.db` |
| 建表脚本 | `server/schema.sql`（28 张表） |
| 首次启动 | 自动创建 `server/data/` 目录、自动执行建表语句，**不需要手动初始化** |
| 上传文件 | 同目录下的 `uploads/`（图片）、`covers/`、`videos/`、`bgm/`，启动时自动创建 |

## 二、SQLite 驱动是三级兜底

`server/db-driver.js` 在启动时依次尝试，哪个能用就用哪个，对外接口完全一致：

| 顺序 | 驱动 | 说明 |
|---|---|---|
| 1 | `better-sqlite3` | 原生模块，最快。需要能编译（Windows 上通常有预编译包） |
| 2 | `node:sqlite` | Node 22 自带，启动时带 `--experimental-sqlite` 更快 |
| 3 | `node-sqlite3-wasm` | 纯 WASM，**一定能跑**，只是稍慢 |

所以 `npm install --omit=optional`（跳过原生模块）也能正常使用，会自动落到第 3 个。
想强制指定：环境变量 `DB_DRIVER=wasm`。

## 三、表清单（28 张）

| 分类 | 表 |
|---|---|
| 账号 | `user`、`user_profile`、`user_settings`、`user_follow` |
| 记忆库 | `memory_space`、`memory_item`、`memory_media`、`memory_comment`、`memory_item_like`、`favorite` |
| 拾光广场 | `square_post`、`post_like`、`post_comment`、`share` |
| 活动 | `activity`、`activity_join`、`activity_like`、`activity_comment` |
| 3D 房间 | `room_prop`、`pet_config`、`bgm_track` |
| AI | `ai_conversation`、`ai_message`、`app_secret` |
| 消息 | `private_message`、`notification` |
| 系统 | `system_config`、`feedback`、`report` |

几个关键设计：

- `memory_item.space_id` 指向 `memory_space`（记忆岛）；`is_public = 1` 表示已分享到广场。
- `square_post.memory_id` 把广场动态绑到记忆库条目——**发布广场动态时是先落记忆库、再投影成动态**，
  所以同一条内容在记忆库和广场是同一份数据，改一处两处都变。
- `app_secret` 存超级管理员在后台设置的 AI 密钥；有值时优先于环境变量，清空则回落到 `.env`。
- `user.password` 存的是加盐哈希（不可逆）；另有 `password_enc` 存可逆密文，仅供管理中心展示。
  密钥由环境变量 `PASSWORD_ENC_KEY` 提供，没有时首次启动自动生成 `server/data/secret.key`。

## 四、备份与恢复

```bash
# 备份（输出到 server/data/backups/）
npm run data:backup

# 恢复：先停掉后端，把备份文件复制回 server/data/timepick.db，再重启
```

改代码前、换数据库前、要做危险操作前，先 `data:backup` 一次。整个库只有几百 KB。

## 五、注意

**交付包里没有带任何 `.db` 文件**，这是故意的：

- 线上库里有真实用户的手机号、密码哈希、私信内容，属于个人隐私，不能随比赛材料扩散；
- 空库启动时会自动建表，评审跑起来完全一致；
- 需要演示数据时用 `npm run seed:demo`（8 个演示账号 + 5 条动态，密码 `demo123456`）。

`server/data/` 已在 `.gitignore` 中，正常提交代码也不会把它带上去。
