# 拾光 TimePick

### AI 辅助的个人数字记忆空间

让生活中的文字、照片与声音，成为可以重新走近的记忆。

拾光将多媒体记录、AI 辅助创作与三维空间探索结合起来。你可以记录日常、保存重要时刻，让 AI 帮助提炼标题、绘制封面、生成视频，也可以走进三维记忆空间，通过一件件物件回顾自己的故事。

[在线体验](https://timepick-memory.app.workbuddy.host/) · [快速开始](#快速开始) · [技术栈](#技术栈)

## 关于项目

照片保存在相册，文字散落在备忘录，声音与视频又留在不同文件夹中。记录越来越多，重新找回一段经历却不总是容易。

拾光希望让记忆拥有一个可以持续积累、整理和探索的空间：既保留原始素材，也借助 AI 为记录提供新的表达方式；既支持个人回顾，也允许用户自主选择分享。

正式作品名称：**拾光——AI 辅助的个人数字记忆空间**。

## 功能亮点

| 功能 | 你可以做什么 |
| --- | --- |
| 多媒体记忆库 | 保存文字、照片、音频与视频，按时间和空间筛选记录 |
| 三维记忆空间 | 在房间中探索承载记忆的物件，重新回顾生活片段 |
| 语义检索匹配物件 | 按「意思」而不是「关键词」选物件：写「合上书」给一本绿皮书，写「外婆煮的面」给杯子。字面检索 + 向量检索融合打分，结果落库，重排与重启都不漂移 |
| AI 文字助手 | 提炼记忆标题、润色正文，为记录整理表达 |
| AI 记忆伙伴「小橘」 | 结合已有记忆上下文聊天，辅助回忆与查找；**可以用文字或说话提问，小橘用语音回答** |
| 记忆语义搜索 | 搜索框里换个说法也能找到（「想念外婆」能命中标题写的是「台灯」的那条） |
| AI 记忆封面 | 将记忆文字转化为水彩风格封面 |
| 图生视频 | 以用户照片或 AI 封面为视觉参考，生成动态记忆片段 |
| 语音转文字 | 将录音转换为文本，辅助输入与记录 |
| 分享与互动 | 公开分享、关注、评论、私信及访问他人空间 |
| 举报与处置 | 管理员可下架被举报内容，并以「拾光管理员」匿名私信通知举报人与作者（双方可直接回复，但看不到是谁） |
| 隐私设置 | 根据个人意愿设置记忆的可见性 |

## 从记录到空间

1. **记录生活**：写下经历，添加照片、声音或视频。
2. **丰富表达**：按需使用 AI 标题、润色、封面和视频能力。
3. **形成空间**：AI 根据标题与正文匹配预制物件，程序分配位置与朝向。
4. **重新回顾**：进入三维空间探索记忆，与小橘交流，或将故事分享给他人。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 前端 | Vue 3、Vite |
| 状态管理与路由 | Pinia、Vue Router |
| 三维展示 | Cocos Creator 3.8.8 导出的 Web 资源 |
| 后端 | Node.js、Express |
| 数据库 | SQLite |
| 文本生成 | DeepSeek · `deepseek-chat` |
| 向量检索 | 阿里云百炼 · `text-embedding-v3`（1024 维） |
| 封面生成 | 智谱 · `cogview-3-flash` |
| 语音识别 | 阿里云百炼 · `qwen3-asr-flash` |
| 语音合成 | 阿里云百炼 · `qwen3-tts-flash`（Cherry 音色） |
| 图生视频 | 阿里云百炼万相 · `wan2.2-i2v-flash` |

前后端共用一个 npm 工程。生产模式由 Express 在同一端口提供页面、API 与静态资源；SQLite 首次启动时自动建库建表，无需额外安装数据库服务。

### AI 如何参与记忆表达

- **文本到物件**：两条通道一起判 —— ① 字面通道把 13 件物件的名称、别名、关键词做中文单字与二元切词，算 TF‑IDF 余弦；② 向量通道把同一份语料和记忆正文都映射成 1024 维向量算相似度。两路按 0.55 : 0.45 融合，取最高分；分差不够明确且配了 DeepSeek 时再问一次大模型兜底。位置、朝向和高度由规则程序计算。
- **文本到封面**：DeepSeek 生成画面描述，智谱生成图像，结果转存到本地。
- **图片到视频**：优先使用用户照片，否则使用 AI 封面，结合记忆文本提交视频任务，轮询完成后保存结果。
- **记忆对话**：将已有记忆作为提示词上下文，辅助生成回答；回答按「首句 + 长尾」两段并发合成语音，首句回来就开口。
- **记忆检索**：字面检索 0 命中时才走向量召回，阈值 0.5 且要求与次高分拉开 0.1，避免"什么都算相关"。

物件判定结果会写进 `memory_item.prop_furniture` 一列，房间布局只读这一列，因此重排、重启、换机都不会让房间"变样"；向量服务不可用（没配密钥、断网、额度用尽）时自动退回字面检索，功能不中断。

## 快速开始

### 环境准备

- 建议使用 **Node.js 22.22.x** 与配套 npm（`DB_DRIVER=node:sqlite` 用到 Node 22 内置的 SQLite 模块；若使用更早版本，请删掉该行，驱动会自动降级到 WASM 版）。
- 使用支持 **WebGL 2.0** 的现代浏览器。
- 仓库内已有 `public/room3d/` 构建资源，运行网站无需安装 Cocos Creator。

本仓库的 npm 工程位于 `源码/` 子目录（仓库根目录只放 3D 工程、说明文档与提交包）。先取到本地并进入该目录，以下命令都在这里执行：

```bash
git clone https://github.com/asdasd123-w/TimePick.git
cd TimePick/源码
```

### 1. 安装依赖

```bash
npm ci
```

若原生模块安装脚本失败，可尝试 `npm ci --ignore-scripts`，并使用下方的内置 SQLite 驱动配置。请保留可选依赖，Vite / Rolldown 构建需要对应平台的绑定包。

### 2. 配置环境

源码根目录已附带 **`.env.example`**（逐项注释，只有占位符、不含任何真实密钥）。复制一份再改成自己的值：

```bash
cp .env.example .env.local        # Windows: copy .env.example .env.local
```

其中三项必须改：

| 变量 | 说明 |
| --- | --- |
| `JWT_SECRET` | 登录令牌签名密钥，随便一串 32 位以上随机字符 |
| `SUPER_ADMIN_USERNAME` | 超级管理员的**注册手机号**。代码里不再提供默认值，不填则管理员授权、AI 密钥等超管功能不可用（启动日志会给出提示） |
| `REGISTER_PASSPHRASE` | 注册口令，注册新账号时要输入 |

`DEEPSEEK_API_KEY`、`ZHIPU_API_KEY`、`DASHSCOPE_API_KEY` 留空也能启动，只是对应的 AI 功能关闭。

可通过以下命令生成随机密钥：

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

AI 配置只放在服务端，勿将真实密钥写入前端源码。启用相应功能需要服务账户与可用额度。

### 3. 构建并运行

```bash
npm run build
node --env-file=.env.local server/index.js
```

打开 [http://localhost:8787](http://localhost:8787)。

使用 `--env-file` 可以在模块初始化前加载配置。首次运行会自动创建数据库；首次访问前需要完成前端构建。生产配置 `.env.production` 使用 `VITE_CLOUD_API_BASE=/api`，页面与接口同源访问。

### 4. 注册账号

在页面注册时填写手机号、昵称、密码和 `.env.local` 中设置的注册口令。

需要管理功能时，先注册，再将以下占位替换为注册手机号执行：

```bash
node --env-file=.env.local scripts/make-admin.mjs YOUR_REGISTERED_PHONE
```

退出并重新登录后生效。

### 开发模式

分别打开两个终端：

```bash
# 终端一：前端，通常为 http://localhost:5173
npm run dev
```

```bash
# 终端二：后端，默认 http://localhost:8787
node --env-file=.env.local server/index.js
```

开发模式使用 `.env.local` 中的完整 API 地址。修改前端后，可执行 `npm run check:undef` 检查未定义标识符。

## 项目结构

下表是 `源码/` 目录内部的结构。仓库根目录另有 `02-3D房间工程/`（Cocos Creator 工程源码）、`03-运行与部署说明/`、`04-作品文档/` 与 `Git提交记录.md`。

| 路径 | 说明 |
| --- | --- |
| `src/` | Vue 页面、组件、状态与接口客户端 |
| `public/` | 背景、音乐及其他静态资源 |
| `public/room3d/` | 三维房间 Web 构建产物 |
| `server/index.js` | Express 服务与业务接口 |
| `server/room.js` | 物件摆放、房间布局与承托关系 |
| `server/propSearch.js` | 物件的字面检索（单字 + 二元切词，TF‑IDF 余弦） |
| `server/propEmbed.js` | 物件的向量检索与融合判定（`text-embedding-v3`） |
| `server/memorySearch.js` | 记忆的语义搜索（换说法也能找到） |
| `server/db.js` | 数据库初始化与迁移 |
| `server/schema.sql` | 基础表结构 |
| `server/db-driver.js` | SQLite 驱动适配 |
| `scripts/` | 构建、检查、授权与数据维护脚本 |
| `.env.example` | 环境变量模板，复制为 `.env.local` 后填值 |
| `vite.config.js` | 前端开发与构建配置 |

运行数据位于 `server/data/`，默认数据库为 `server/data/timepick.db`。部署更新时应保留数据目录，备份时同时保存数据库、关联媒体及必要的加密密钥。
