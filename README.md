# 拾光 TimePick · 记忆可视化空间

把一段段记忆放进一座座会呼吸的岛：写下的事不再堆成列表，而是变成漂浮的记忆岛，
点进去是一座可以走动的 3D 房间——家具、窗前的光、脚边跟着你的小猫。

**在线演示**：https://timepick-memory.app.workbuddy.host/

## 30 秒跑起来

```bash
cd 源码
npm install
cp ../03-运行与部署说明/环境变量示例.env .env.local   # Windows: copy ..\03-运行与部署说明\环境变量示例.env .env.local
npm run build
node server/index.js            # → http://localhost:8787
```

注册后创建第一个管理员：

```bash
npm run admin:grant -- 13800138000     # 换成你刚注册的手机号
```

环境要求：Node.js ≥ 20.11。不需要装数据库，SQLite 随进程启动。
3D 房间的构建产物已包含在 `源码/public/room3d/`，**不需要安装 Cocos Creator** 就能跑起来。

---

## 技术栈

Vue 3（`<script setup>`）· Vite · Pinia · vue-router · Express 5 · SQLite（三级驱动兜底）· Cocos Creator 3.8.8

单一 Node 进程同时托管前端与 `/api`，一个端口、一台最小规格云主机即可运行。
