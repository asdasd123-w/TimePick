二、跑起来只要四步
────────────────────────────────────────────────────────────
  cd 源码
  npm install
  copy ..\03-运行与部署说明\环境变量示例.env .env.local   （macOS/Linux 用 cp）
  npm run build
  node server/index.js            → 浏览器打开 http://localhost:8787

  注册后创建管理员：npm run admin:grant -- 你的手机号
  详细说明见 03-运行与部署说明/运行说明.md
