把演示视频放在这个文件夹里。

要求（按第九届传智杯 AI WEB 网页开发挑战赛）：
  · 时长 5~8 分钟
  · MP4 格式，分辨率不低于 1080p
  · 普通话讲解，需要有人声说明，不要只放背景音乐
  · 不得超过平台单个附件大小限制（若超了，传到 B 站/网盘，这里改放一个"视频链接.txt"）

建议文件名：学校+姓名+作品名+演示视频.mp4
例：某某大学+张三+拾光TimePick+演示视频.mp4

一、录制前的准备（很重要，能省下大量重录时间）
────────────────────────────────────────────────
  1. 先按 03-运行与部署说明/运行说明.md 把项目跑起来，确认：
     首页能开、能注册登录、能建岛写记忆、广场有内容、3D 房间能进
  2. 准备演示数据：npm run seed:demo（8 个演示账号 + 5 条动态）
     或者提前手动注册 3~4 个账号，各发 2~3 条记忆，让广场和推荐位看起来是活的
  3. 浏览器缩放调到 100%，窗口 1920×1080，关掉其它标签页、通知和书签栏
  4. 如果 AI 密钥已配置，先把"AI 取标题"要用的那条记忆内容准备好——
     AI 生成有 3~10 秒等待，提前想好讲什么，别让画面空转
  5. 3D 房间第一次进要加载 20 秒以上（130 MB 资源）。**先单独打开一次让它缓存**，
     正式录的时候再进就很快，不会在视频里出现长时间等待

二、推荐的讲解顺序（总时长约 6~7 分钟）
────────────────────────────────────────────────
  ① 开场 30 秒
     "这是我做的作品：拾光 TimePick，一款把生活记忆变成可以走进去的 3D 房间的记忆管理应用。
      技术上用 Vue 3 + Express + SQLite，3D 部分用 Cocos Creator 3.8.8。"

  ② 记忆库 90 秒
     登录 → 首页 → 进入记忆库
     新建一座记忆岛（起名、选封面）→ 写一条记忆（正文 + 传一张图 + 选日期）
     重点讲：点"AI 取标题"后标题自动变成 2~4 个字（这是 DeepSeek 做的）
     保存 → 卡片出现在记忆岛里，封面是 AI 生成的（这是智谱 CogView 做的）

  ③ 分享到广场 60 秒
     打开刚写的记忆 → 选择"分享到广场"
     重点讲：发布广场动态走的是和记忆库同一套落库流程，
              广场那条动态和记忆库里那条记忆是同一份数据，改一处两处都变；
              删掉广场动态只是取消公开，记忆本身还在。
     切到拾光广场看动态流，右侧"推荐记忆空间"会推荐其他用户。

  ④ 3D 房间 120 秒（这是最出彩的一段，讲慢一点）
     进入 3D 房间 → 先展示加载页（小猫跑酷 + 真实下载进度条）
     重点讲：3D 首屏要加载 130 MB，等待期间给了一个可以玩的小游戏，
              进度条不是假的，是按真实下载字节数算的
     进入房间 → 环视 → 摆放/旋转一件家具 → 和宠物互动 → 打开房间里的记忆展示
     重点讲：房间和记忆库是打通的，摆进来的记忆就是记忆库里的那条

  ⑤ 社交与活动 60 秒
     广场点赞评论 → 关注一个用户 → 私信发一句 → 通知中心看到未读
     活动列表 → 打开"秋日跑" → 点报名，人数从 N 变成 N+1（实时落库，刷新仍然是 N+1）

  ⑥ 管理中心 60 秒
     用超级管理员登录 → 管理中心
     用户管理：讲超级管理员那一行为什么是锁死的（不可删除/不可禁用/不可取消/密码不可重置，
                且密码对任何管理员都不可见）
     AI 使用：讲三栏密钥分别控制什么功能，保存后立即生效，不需要重启
     重点讲：这一块体现的是"权限边界"和"运行时可配置"的产品化思考

  ⑦ 收尾 30 秒
     技术架构一句话总结 + 创新点（记忆与广场同一份数据、3D 记忆房间、AI 三模型分工）
     + 给出在线演示地址

三、录制小技巧
────────────────────────────────────────────────
  · 用 OBS Studio 或 Windows 自带 Xbox Game Bar（Win+G）录，1080p 30fps 足够
  · 先照着上面的脚本空跑一遍（不录），把"哪里点了没反应、哪里要等待"都摸清
  · 讲解要跟着操作走，不要出现"我点一下这个……嗯……等一下"的大段空白
  · 3D 房间那段如果卡顿，单独重录这一段再剪进去
  · 导出后自己完整看一遍：有无卡顿、有无暴露手机号/密码/密钥等隐私信息
